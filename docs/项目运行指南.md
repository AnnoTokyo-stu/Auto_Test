# 项目运行指南

## 一、创建解释器

建议在 PyCharm 中使用 Python 3.10 或更高版本创建虚拟环境，然后在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
```

Chrome 为默认浏览器。Selenium Manager 会自动处理兼容驱动；受限网络下可通过 `WEB_DRIVER_PATH` 或 `--driver-path` 指定本地 ChromeDriver。

登录页存在随机图形验证码。脚本填写账号和密码后，会在可见 Chrome 中等待人工输入 4 位验证码，检测完成后自动点击登录。等待时间由 `WEB_MANUAL_CAPTCHA_TIMEOUT` 控制，默认 120 秒；验证码场景不要使用 `--headless`。

生产环境注册同时包含图形验证码和邮箱验证码。WEB-001 会等待人工输入两类验证码；每次完整输入后按 `Tab` 让输入框失去焦点，脚本才继续。邮箱验证码默认最长等待 300 秒。该用例会创建真实生产账号，只有同时传入 `--run-ui --run-destructive --confirm-production-registration` 才执行。

## 二、配置运行环境

项目启动时会自动读取根目录 `.env.local`。该文件已被 `.gitignore` 忽略，只能保存经批准的本机专用测试账号，禁止分享、上传或提交。终端和 PyCharm 已设置的同名环境变量优先级更高，不会被本地文件覆盖。

首次使用可参考 `.env.local.example`。注册账号和登录账号已通过变量引用关联，只需填写一套注册数据：

```dotenv
WEB_REGISTRATION_ACCOUNT="专用测试账号"
WEB_REGISTRATION_PASSWORD="专用且不复用的测试密码"
WEB_REGISTRATION_NAME="测试姓名"
WEB_REGISTRATION_PHONE="专用测试手机号"
WEB_REGISTRATION_EMAIL="专用测试邮箱"
```

修改依赖后需要再次执行：

```powershell
python -m pip install -r requirements.txt
```

然后补齐：

1. `page/` 下的 TODO 定位器。
2. `data/*.json` 中的 `__TO_BE_CONFIRMED__`。
3. `.env.example` 所列的测试账号和已准备业务编号。

## 三、安全执行规则

默认命令只收集并跳过真实 UI：

```powershell
pytest
```

执行只读登录冒烟：

```powershell
pytest -m smoke --run-ui --browser=chrome
```

执行会新增或修改测试数据的 P0 用例：

```powershell
pytest -m p0 --run-ui --run-destructive --browser=chrome
```

切换 Edge 不修改代码：

```powershell
pytest -m smoke --run-ui --browser=edge
```

无头运行：

```powershell
pytest -m smoke --run-ui --browser=chrome --headless
```

## 四、Allure 报告

Pytest 默认把原始结果写入 `report/`：

```powershell
allure serve report
```

生成离线 HTML：

```powershell
allure generate report -o report-html --clean
```

Allure 命令行需要本机安装 Java 和 Allure。即使未安装 Allure 命令行，pytest 仍可生成原始结果。

## 五、常用排查

```powershell
# 只检查用例收集
pytest --collect-only

# 执行单条逻辑用例
pytest script/test_01_auth.py::test_web_009_redirect_unauthenticated_user --run-ui

# 查找未填写定位器
Get-ChildItem page -Recurse -Filter *.py | Select-String "todo_locator"

# 查找未确认数据
Get-ChildItem data -Recurse -Filter *.json | Select-String "__TO_BE_CONFIRMED__"
```

出现失败时依次查看：终端异常、`log/web.log`、`screenshots/` 和 Allure 附件。
