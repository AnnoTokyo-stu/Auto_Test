## 一、推荐定位顺序

1. 唯一且稳定的 `id`。
2. 业务稳定的 `name`、`data-testid`、`data-*` 属性。
3. 语义稳定的 CSS 选择器。
4. 相对 XPath。

避免绝对 XPath、动态下标、样式层级和构建工具生成的随机 class。

## 二、填写示例

修改前：

```python
USERNAME_INPUT = todo_locator("登录账号输入框")
```

修改后可使用 Selenium 的 `By`：

```python
from selenium.webdriver.common.by import By

USERNAME_INPUT = (By.ID, "username")
```

或直接使用 WebDriver 标准定位字符串：

```python
USERNAME_INPUT = ("css selector", "input[name='username']")
```

## 三、操作步骤

1. 使用 Chrome 打开目标页面并按 `F12`。
2. 使用元素选择器选中目标控件。
3. 优先查找唯一 `id`、`name` 或 `data-testid`。
4. 在 Console 执行定位表达式，确认只命中一个元素：

   ```javascript
   document.querySelectorAll("input[name='username']").length
   ```

5. 将定位器填写到对应 `page/*.py` 顶部。
6. 使用以下命令查找仍未填写的定位器：

   ```powershell
   Get-ChildItem page -Recurse -Filter *.py | Select-String "todo_locator"
   ```

7. 先运行登录冒烟，再逐模块验证：

   ```powershell
   pytest -m smoke --run-ui --browser=chrome
   ```

## 四、动态页面排查

- 元素加载慢：由 `BasePage` 显式等待处理，不添加固定休眠。
- 元素在 iframe：先调用 `switch_to_frame()`，操作后调用 `switch_to_default_content()`。
- 点击后打开新窗口：记录原句柄集合，再调用 `switch_to_new_window()`。
- 自定义下拉框：不要使用 Selenium `Select`，应分别定位下拉入口和选项。
- 原生 `<select>`：使用 `select_by_text()` 或 `select_by_value()`。
- 元素被遮挡：检查加载层、弹窗和滚动位置，不直接使用 JavaScript 强制点击掩盖问题。

## 五、定位完成验收

- 定位表达式唯一且稳定。
- 页面对象中没有绝对 XPath。
- 每个 TODO 均已替换或明确记录暂缓原因。
- 登录、退出、菜单跳转可重复执行三次。
- 定位失败时日志能指出具体定位器，Allure 中存在失败截图。
